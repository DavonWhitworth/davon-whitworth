2DRunner is a 2D platformer built with Unity and C#. The player navigates side-scrolling levels, jumps across platforms, avoids hazards, and interacts with enemies and moving objects. Unity’s 2D physics system handles movement, collisions, triggers, and rigidbodies, while C# scripts control player health, armor, jumping, enemy behavior, level resets, moving platforms, and camera movement.

The project also uses Unity’s Animator system for player and enemy animations, Sprite Renderers for visual elements such as health and armor bars, and Unity scenes, prefabs, and imported pixel-art assets to construct the game world. The `GameController` manages level state and restarts, while scripts such as `EnemyIntelligence` and `ItemMovement` provide basic enemy pursuit and environmental movement.
