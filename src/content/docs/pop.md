Pop is a top-down arcade shooter focused on surviving waves of enemies. Players control one or two characters, move and aim using twin-stick or keyboard/mouse controls, defeat enemies, collect weapons and power-ups, and manage lives, armor, ammunition, and score. Enemy waves are scheduled over time, enemies pursue the players, and the game includes features such as sentry guns, weapon drops, temporary upgrades, pause and game-over states, sound effects, and animated menus.

The game is built with Unity 2021.2.7f1 and C#. Unity’s physics and collision systems handle player movement, enemy contact, projectiles, and particle-based weapon effects. C# scripts manage the game state, two-player controls, enemy AI, wave spawning, scoring, lives, power-ups, and audio. Unity’s Animator system provides character and interface animations, while particle systems, prefabs, sprites, audio clips, and materials create the game’s visual and gameplay effects. The project also includes WebGL integration so the game can communicate with a web page when it has finished loading.
