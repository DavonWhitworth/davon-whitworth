KB-Jewels is a promotional website for a custom jewelry business. It presents the company’s story, jewelry portfolio, testimonials, media, and contact information through a polished, image-focused interface. The site is designed to help visitors learn about the jeweler’s work and submit inquiries about custom pieces.

The project uses Next.js with React and TypeScript, using the App Router for page organization and server/client component separation. Material UI provides layout and interface components, while Next Image optimizes portfolio and promotional images. Framer Motion supports visual animation, and Formik with Yup handles contact-form state and validation. EmailJS sends submitted inquiries, while Google reCAPTCHA helps reduce automated spam.
